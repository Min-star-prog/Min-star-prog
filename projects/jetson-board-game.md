## 개요

실제 보드게임을 카메라로 읽어 기물 배치를 디지털 보드로 옮기고, AI 엔진의 승률·형세·추천 수를 보여주는 시스템입니다. 팀은 체스·장기·바둑·오목을 통합했고, 저는 장기·바둑 인식과 데이터셋 제작, Jetson 배포, 국면 안정화와 엔진·GUI 연동을 담당했습니다.

## 처리 흐름

웹캠 입력 → 보드 꼭짓점 검출 → 투시변환·격자 보정 → 교차점 패치 분류 → 국면 안정화 → AI 엔진 분석 → GUI 표시

## 본인 구현

- ArUco 기준점과 격자 좌표를 이용한 데이터셋 수집·분류 스크립트 작성
- YOLO11-Pose 꼭짓점 검출과 Perspective Transform 적용
- 장기 90개 교차점을 96×96 패치로 추출해 경량 CNN으로 기물·빈칸 분류
- 바둑 361개 교차점을 32×32 패치로 추출해 ResNet18로 흑돌·백돌·빈칸 분류
- ONNX·TensorRT 변환과 Jetson Orin Nano 배포
- 장기 FEN을 Fairy-Stockfish에, 바둑 국면을 KataGo에 전달
- 인식 화면·디지털 보드·분석 결과를 GUI에 표시하고 4종 게임 런처 통합

## 검증 결과

| 모델·대상 | 결과 | 평가 범위 |
| --- | --- | --- |
| 장기 꼭짓점 · YOLO11s-Pose | 평균 오차 17.21 px · Pose mAP50 0.989 | Validation |
| 장기 기물 · 경량 CNN | 정확도 99.14% | Validation Overall Accuracy |
| 바둑 꼭짓점 · YOLO11n-Pose | 평균 오차 17.48 px · Pose mAP50 0.948 | 최종 발표자료 기준 |
| 바둑 돌 · ResNet18 | 170개 패치 정분류 | 흑돌 25·빈칸 120·백돌 25 테스트 |

이 수치는 모델별 평가이며, 모든 실사용 환경에서 전체 보드를 같은 정확도로 인식했다는 의미로 쓰지 않습니다.

## 문제 해결

촬영 각도·조명에 따라 바둑판 꼭짓점 오차가 커져 새로운 조건에서 촬영한 189장을 추가 라벨링하고 Sobel Edge 기반 격자 보정을 적용했습니다. 손 가림·순간 오인식은 바둑의 동일 국면 2회 확인과 장기의 최근 3프레임 안정화로 보완했습니다. 장기 소형 기물 ‘사’의 분류 실패는 클래스 가중치 조정과 추가 학습으로 점검했습니다.

## 결과

영상 모델을 데이터 제작·후처리·엔진 입력 변환·사용자 화면까지 연결했습니다. 최종 시연에서 남은 촬영 조건별 편차는 추가 데이터와 실제 환경 검증의 과제로 기록합니다.
